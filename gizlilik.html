Gizlilik

IKRA hesap istemez; reklam, analiz ya da takip kullanmaz.

  • Kitapların, kaydettiğin kelimeler, ilerlemen ve ayarların yalnızca kendi cihazında saklanır. Yedek dosyası yalnızca sen kaydedersen oluşur.
  • Uygulama ve Günün Kelimesi sesleri GitHub Pages'ten (GitHub, Inc.) yüklenir; GitHub, her web sitesinde olduğu gibi teknik kayıtlar (ör. IP adresi) tutabilir.
  • Günlük hatırlatıcı — Android'de tamamen cihazda çalışır, hiçbir veri gönderilmez. iPhone/web'de hatırlatıcıyı açarsan sunucumuz (Cloudflare) yalnızca tarayıcının bildirim adresini, saat dilimini, dili ve seçtiğin saati saklar; bildirimi Apple/Google/Microsoft'un bildirim servisi iletir. Hatırlatıcıyı kapatınca kayıt silinir; çalışmayan kayıtlar kendiliğinden silinir.
  • Kitap dosyalarını (.ikra) yalnızca güvendiğin kişilerden aç.

Kelime paketleri: Leipzig Corpora Collection ve OpenSubtitles 2018 (hermitdave/FrequencyWords) sıklıklarından türetildi, CC BY-SA 4.0. Açıklamalar yapay zekâyla (Google Gemini) yazıldı; sesler Microsoft Azure'un yapay sesleridir.

Sorular ve silme istekleri: github.com/resulefekaynar/Ikra

Конфиденциальность

IKRA не требует учётной записи и не использует рекламу, аналитику или отслеживание.

  • Ваши книги, сохранённые слова, прогресс и настройки хранятся только на вашем устройстве. Резервная копия создаётся, только если вы сами её сохраните.
  • Приложение и звуки «Слова дня» загружаются с GitHub Pages (GitHub, Inc.); как и любой сайт, GitHub может вести технические журналы (например, IP-адрес).
  • Ежедневное напоминание — на Android работает полностью на устройстве, данные не отправляются. На iPhone/в браузере, если вы включите напоминание, наш сервер (Cloudflare) хранит только адрес уведомлений браузера, часовой пояс, язык и выбранное время; уведомление доставляет служба Apple/Google/Microsoft. При выключении напоминания запись удаляется; неработающие записи удаляются автоматически.
  • Открывайте файлы книг (.ikra) только от людей, которым доверяете.

Словари: на основе частотных данных Leipzig Corpora Collection и OpenSubtitles 2018 (hermitdave/FrequencyWords), CC BY-SA 4.0. Объяснения написаны ИИ (Google Gemini); голоса — синтезированные голоса Microsoft Azure.

Вопросы и запросы на удаление: github.com/resulefekaynar/Ikra

Құпиялылық

IKRA тіркелгі сұрамайды; жарнама, аналитика немесе бақылау қолданбайды.

  • Кітаптарыңыз, сақталған сөздеріңіз, үлгеріміңіз бен баптауларыңыз тек өз құрылғыңызда сақталады. Сақтық көшірме тек өзіңіз сақтасаңыз ғана жасалады.
  • Қолданба мен «Күн сөзі» дыбыстары GitHub Pages-тен (GitHub, Inc.) жүктеледі; кез келген сайт сияқты GitHub техникалық жазбаларды (мысалы, IP мекенжайын) сақтауы мүмкін.
  • Күнделікті еске салу — Android-та толығымен құрылғыда жұмыс істейді, ешқандай дерек жіберілмейді. iPhone/браузерде еске салуды қоссаңыз, біздің серверіміз (Cloudflare) тек браузердің хабарландыру мекенжайын, уақыт белдеуін, тілді және таңдалған уақытты сақтайды; хабарландыруды Apple/Google/Microsoft қызметі жеткізеді. Еске салуды өшірсеңіз, жазба жойылады; жұмыс істемейтін жазбалар өздігінен жойылады.
  • Кітап файлдарын (.ikra) тек сенімді адамдардан ашыңыз.
